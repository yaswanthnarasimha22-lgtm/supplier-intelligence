# Supplier logo images

Place one `.png` per supplier here.  The filename must match the supplier's
`data-supplier` key exactly (case-sensitive).  Recommended size: square,
256×256 or larger, PNG with transparency.  All cards render the image inside
a 96 px tall media area with `object-fit: contain`, so any square logo works
without cropping.

Expected filenames:

- `hotelbeds.png`        — Hotelbeds account 1 (Hotelbeds1MAF)
- `hotelbeds2.png`       — Hotelbeds account 2 (Hotelbeds2MA) — may reuse the same artwork
- `bedswithease.png`     — Beds With Ease
- `alturabeds.png`       — Altura Beds
- `sunhotels.png`        — SunHotels
- `suninternational.png` — Sun International
- `suntransfers.png`     — SunTransfers
- `stours.png`           — S Tours
- `yalago.png`           — Yalago
- `w2m.png`              — W2M account 1 (HTRUS1)
- `w2m2.png`             — W2M account 2 (TLSHOT) — may reuse the same artwork

If an image is missing, the card falls back to a coloured monogram (the
first two letters of the supplier key) so the launcher still works.
